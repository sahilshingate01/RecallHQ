                  3. DETAILED WEEK-BY-WEEK BREAKDOWN
================================================================================

--------------------------------------------------------------------------------
WEEK 1: FOUNDATIONS
--------------------------------------------------------------------------------

DSA - Arrays & Sorting (Striver A2Z Steps 1-3)
  Day 1: Time/Space complexity, basic math problems
  Day 2: Arrays - easy (largest element, second largest, check sorted)
  Day 3: Arrays - medium (2-sum, sort 0s/1s/2s, majority element)
  Day 4: Arrays - medium (Kadane's algorithm, stock buy/sell, rearrange)
  Day 5: Arrays - hard (3-sum, merge overlapping intervals, missing/repeating)
  Day 6: Hashing basics (frequency count, highest/lowest frequency)

  Codeforces: Div 3/4 A and B problems only (800-1000 rating).
  Focus on reading problems carefully and implementing brute force.

Development:
  Days 1-3: Python or C++ refresher (OOP, file I/O, standard library)
  Days 4-6: JavaScript fundamentals (variables, functions, DOM, async/await)
  Setup: VS Code, Git, GitHub account, Node.js installed

DevOps:
  Days 1-3: Linux basics - navigating filesystem, ls, cd, cat, grep, chmod, pipes
  Days 4-6: File permissions, process management (ps, top, kill), package managers

--------------------------------------------------------------------------------
WEEK 2: CORE DATA STRUCTURES
--------------------------------------------------------------------------------

DSA - Strings & Linked Lists (Striver A2Z Steps 4-5)
  Day 1: String basics (reverse, palindrome check, isomorphic strings)
  Day 2: String medium (longest palindromic substring, anagram grouping)
  Day 3: Linked List basics (insertion, deletion, traversal)
  Day 4: Singly LL problems (reverse, detect cycle, find middle)
  Day 5: Doubly LL + LL medium problems (add two numbers, intersection)
  Day 6: LL hard (reverse in groups of K, flattening)

  Codeforces: Continue 800-1000 rated. Try one 1100 problem per day
  alongside two easier ones.

Development:
  Days 1-2: HTML5 semantic elements, CSS flexbox and grid
  Days 3-4: Responsive design, CSS animations
  Days 5-6: React intro - create-react-app, JSX, components, props

DevOps:
  Days 1-3: Git deep dive - branching, merging, rebasing, resolving conflicts
  Days 4-6: Shell scripting - variables, loops, conditionals, writing automation scripts

--------------------------------------------------------------------------------
WEEK 3: STACKS, QUEUES, RECURSION
--------------------------------------------------------------------------------

DSA (Striver A2Z Steps 6-7)
  Day 1: Stack fundamentals (implement using array/LL, balanced parentheses)
  Day 2: Stack problems (next greater element, stock span, asteroid collision)
  Day 3: Queue fundamentals + monotonic stack/queue
  Day 4: Recursion basics (factorial, Fibonacci, power, print subsequences)
  Day 5: Recursion medium (combination sum, subset sum, permutations)
  Day 6: Recursion hard (N-Queens, Sudoku solver, rat in a maze)

  Codeforces: 900-1200 rated problems. Start identifying patterns
  (greedy, implementation, math).

Development:
  Days 1-2: React hooks (useState, useEffect, useContext)
  Days 3-4: React Router, API calls with fetch/axios
  Days 5-6: State management basics, form handling

DevOps:
  Days 1-3: Docker - what are containers, install Docker, build first image, Dockerfile syntax
  Days 4-6: Docker - run containers, port mapping, volumes, Docker Hub

--------------------------------------------------------------------------------
WEEK 4: BINARY SEARCH + PROJECT 1
--------------------------------------------------------------------------------

DSA - Binary Search & Bit Manipulation (Striver A2Z Steps 8-9)
  Day 1: Binary search on 1D arrays (search, lower/upper bound)
  Day 2: BS on answers (square root, Koko eating bananas, minimum days)
  Day 3: BS on 2D arrays (search in matrix, median of row-sorted matrix)
  Day 4: Bit manipulation basics (set/unset bit, power of 2, count bits)
  Day 5: Bit manipulation problems (single number, XOR queries)
  Day 6: Mixed practice day - revisit weak topics

  Codeforces: 1000-1300 rated. Attempt Div 2 A and B problems from recent contests.

Development - Project 1: Task Management App (Full-Stack)
  Tech: React frontend + Node.js/Express backend + MongoDB

  Days 1-2: Backend setup (Express, MongoDB connection, REST APIs)
  Days 3-4: Frontend (React components, connect to API)

DevOps:

================================================================================
                    4. BURNOUT PREVENTION STRATEGY
================================================================================

1. The 2-day rule: Never skip more than 2 days in a row. Missing one day is fine.
2. Pomodoro technique: 50 min work -> 10 min break. Every 3 cycles, take 30 min off.
3. Rotate when stuck: If a DSA problem takes >45 min, mark it and move on. Return next day.
4. Physical activity: 20-30 min daily (walk, gym, sports). Non-negotiable.
5. Social time: Evenings are free. Don't study after 6 PM unless you genuinely want to.
6. Weekly reward: After each Saturday session, do something you enjoy guilt-free.

================================================================================
                            FINAL TIPS
================================================================================

1. DSA is king for interviews at FAANG. Never skip DSA days, even when
   projects are exciting.

2. Quality over quantity on Codeforces - understand WHY a solution works,
   not just WHAT the solution is. Read editorials for every problem.

3. One project well-built > five half-finished ones. Make your 3 projects
   genuinely impressive.

4. Start applying by Week 6, not Week 8. Applications take time to process.

5. Join communities: Striver's Discord, Codeforces Telegram groups, and
   r/cscareerquestions for motivation and peer learning.
